## 二、耦合性分析

### 2.1 编译期分层：全仓最干净的部分

- ✅ 无循环依赖；依赖方向严格单向。
- ✅ **UI 未引用任何实现层类型**，也没 `new` 实现类；Agent / Tools / Backend / Imaging 四者**零互相引用**。
- ✅ Contracts 未引用 Avalonia / 其他 `ZivAiEditor.*`。
- ✅ App 无任何 XAML `{Binding}` / `DataContext`（全部 code-behind），绑定错误风险为零，但代价见 2.4。

## 三、代码审核发现

### 3.1 高危（稳定性 / 正确性 / 安全）

| # | 模块 | file:line | 问题 | 核验 |
|---|---|---|---|---|
| **A1** | Python | `main.py:81-90` + `ipc.py:128-136` | **可轮询模式下管道断开无法检测 → 后端孤儿空转**。客户端断开后 `PeekNamedPipe` 失败使 `has_pending_frame()` 恒为 `False`，主循环 `return None → sleep` 永不结束，已加载模型 / 显存长期不释放 | ✅ 回读确认 |

## 四、优先修复建议（按性价比排序）

1. **A2 推理超时语义**：拆分「加载超时」与「采样超时」，超时分支同样 `TryForwardCancelAsync` / 重启后端。这是最容易在真实使用中暴露的坑。
2. **A1 断连检测**：`has_pending_frame` 区分「无数据」与「管道已断」，主循环据此退出；否则孤儿后端将长期占 GPU。
3. **A3+A4 显存生命周期**：把 `busy 检查 + unload + release_vram` 收进同一把锁；加载异常分支强制 `_release_vram()`。
4. **A5 路径穿越**：`GetDirectory` 内 `Path.GetFileName` 校验 + `Path.GetFullPath` 归属校验（Agent 与 SessionStore 单点实现）。
5. **A6 `RemoveSubtree` 不变式**：把重定向逻辑移出 `includeStart` 门控，补齐回归测试。
6. **B4/B5 契约字段**：给 `MagCache` 加 `[JsonPropertyName("magcache")]` 并统一契约；`ApplyResolution` 补 `ModelId`。
7. **B1/B2 UI 性能**：`RebuildContext` 期间挂起渲染、批量结束一次性 `RenderChat`；预览 JPEG 移出 UI 线程解码。
8. **B6 单实例管道**：加 `PipeSecurity` + 消息长度上限。

**架构层面**（非紧急但影响长期维护）：

- 移除 `DiagLog` 对 Contracts 的 IO 污染（下沉到独立诊断程序集或改由注入）。
- 拆 `MainWindow`（≈3100 行 / 30 共享字段）为 `ChatRenderer` / `ProjectController` / `PreviewController` / `CommandPopupController` / `MaskController`，共享状态收敛为单一 context。
- 清理 Contracts / App 中**零使用**的 ZIV.Core / ZIV.Imaging 冗余引用；评估把 `D:\devlop\ZIV` 相对路径依赖改为 NuGet 或 submodule 以保证 CI 可复现。

## 五、总体结论

- **架构方向优秀**：端口 / 适配器、依赖单向、域实现解耦、契约纯净（除 DiagLog）、纯逻辑下沉可单测、Python 侧 CPU 纯函数模块可测——这是全仓最强项，且文档（ARCHITECTURE / INTERFACES / FROZEN）与实现基本吻合。✅ 等级的分层合规在抽样中逐一确认。
- **主要风险集中在三处**：① **GPU / 进程生命周期**（Python 竞态与显存释放、C# 超时 / 取消语义、断连检测）；② **UI 层负载与上帝类**（O(n²) 重建、UI 线程解码、MainWindow 3000+ 行）；③ **路径信任边界**（sessionId 未校验、loader 接受绝对路径）。
- **工程化短板**：生产日志几乎只有 `Debug.WriteLine`（Release 失效）可观测性弱；契约不一致虽少但存在（MagCache）；外部仓库硬路径依赖影响可移植性。

> 高危及关键中危条目（A1–A6 / B4 / B5）已回读原始文件核验，结论与代码一致；其余条目来自逐文件深挖，可信度高但未逐条亲验，落地前建议对目标项再确认一次。
